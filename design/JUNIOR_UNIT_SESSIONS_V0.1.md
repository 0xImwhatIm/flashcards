# Junior FlashCards subunit sessions v0.1

Updated 2026-09-22 from the classroom pacing request.

## Session map

| Session | Cards | Scope |
|---|---:|---|
| Unit 1-1 | 20 | Unit 1 cards 1–20 |
| Unit 1-2 | 9 | Unit 1 cards 21–29 |
| Unit 2-1 | 20 | Unit 2 cards 1–20, including `Color` + `Colorful` |
| Unit 2-2 | 20 | Unit 2 cards 21–40, including `Person` + `Persons` + `People` |
| 國中綜合 | 69 | All Unit 1 and Unit 2 cards |

The 20-card boundary is a pacing rule, not a second vocabulary authority. The original word order is preserved inside each unit, while related extension words are deliberately kept together. `Persons` uses the same plural three-dinosaur visual as `People` and is an explicit extension of `Person`.

The elementary course sessions remain unchanged. The junior course selector renders the four subunits plus the all-in-one review session; Learn and Spell continue to operate on whichever subunit is selected.
